# 📖 Overview

This repository contains my complete solutions to the **Striver SDE Sheet**, one of the most popular interview preparation roadmaps for Software Development Engineer (SDE) roles.

The repository follows the original **60 Days Study Plan**, covering a wide range of Data Structures and Algorithms topics that are frequently asked in coding interviews at top product-based companies.

Every problem has been solved in **C++**, focusing on writing clean, optimized, and interview-friendly code while strengthening problem-solving skills and algorithmic thinking.
